# BossECU Studio
BossECU Studio is the tuning and configuration software for compatible Honduino and BossECU engine management systems.
It lets you connect to your ECU, configure engine settings, adjust calibration tables and monitor live engine data.

## Features

- Create and manage ECU projects
- Configure engine and sensor settings
- View and edit tuning tables
- Monitor live ECU data
